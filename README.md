# Steering Through the Trees: Physical Lie Vector Field Evasion of Tree Ensembles in Network Intrusion Detection

[![Python 3.13](https://img.shields.io/badge/python-3.13-blue.svg)](https://www.python.org/)
[![CUDA Accelerated](https://img.shields.io/badge/CUDA-XGBoost%20CUDA-green.svg)](https://developer.nvidia.com/cuda-toolkit)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)
[![Target Journal](https://img.shields.io/badge/Journal-Elsevier%20Information%20Sciences-orange.svg)](https://www.sciencedirect.com/journal/information-sciences)

Reference implementation of **Flow-Field Evasion (FFE)**, a constraint-preserving evasion attack against gradient-boosted tree ensembles in flow-based network intrusion detection. FFE models four protocol-compliant attacker actions (temporal dilation, payload padding, chaff injection, TCP window morphing) as infinitesimal generators of a Lie cone on the flow manifold and finishes with tree-split boundary snapping (TSBS).

## 1. What the benchmark measures

All results are computed on the **complete, deduplicated** CSE-CIC-IDS2018, CIC-IDS2017 and UNSW-NB15 captures (no sampling), mapped to a 12-feature flow schema.

| Dataset | Raw rows | Valid | Exact duplicates removed | Kept | Attacks | Train / Test |
| :--- | ---: | ---: | ---: | ---: | ---: | :--- |
| CSE-CIC-IDS2018 | 8,284,254 | 8,153,708 | 3,185,319 | 4,968,389 | 594,809 | 3,477,872 / 993,679 |
| CIC-IDS2017 | 2,099,971 | 2,085,851 | 426,982 | 1,658,869 | 396,403 | 1,161,208 / 331,774 |
| UNSW-NB15 | 257,673 | 215,689 | 92,181 | 123,508 | 55,559 | 86,456 / 24,703 |

Notes: the distributed CSE-CIC-IDS2018 files are capped at 1,048,575 rows each; the UNSW-NB15 files are the official training/testing partition (a subset of the 2.54 million records of the complete capture). Records with identical features and label are collapsed before the stratified 70/10/20 split; records with identical features but different labels are **kept** (149,526 / 22 / 1,040). UDP flows are kept (CICFlowMeter's window of -1 becomes 0); CIC-IDS2017 "Attempted" probe records are removed and "Infiltration - Portscan" is counted as port scanning. The split is random, so near-duplicate flows can fall on both sides and accuracies are optimistic.

## 2. Main results (XGBoost target; Real ASR = evades **and** schema-feasible, in %)

Every number is regenerated by `experiments/summarize_results.py` from `results/*.json`; Wilson intervals, PFR and costs are in `paper/tables/tab_master.tex`.

| Method | CSE-CIC-IDS2018 | CIC-IDS2017 | UNSW-NB15 | Target queries |
| :--- | :---: | :---: | :---: | :---: |
| Unconstrained feature space | 32.4 | 22.3 | 0.2 | 38--67 |
| ZOO-NIDS | 25.2 | 21.8 | 0.0 | 80--130 |
| HopSkipJump-NIDS | 0.0 | 0.0 | 0.0 | 47 |
| MOEVA, search stage of CAA (N=200) | 28.5 | 38.0 | 13.0 | 226--445 |
| PSO, Traffic Manipulator, projected (N=200) | 54.0 | 35.0 | 42.0 | 183--251 |
| CAPGD, surrogate transfer | 88.5 | 89.5 | 21.1 | 3.2--16.2 |
| NIDSGAN-style generator | 61.3 | 65.3 | 11.3 | 2.4--4.5 |
| **FFE (ours, white-box)** | **99.5** | **99.2** | **57.6** | 14.6--93.7 |

What this does and does not show:

* FFE is significantly better than every baseline on every corpus (exact McNemar, Holm-corrected over 21 comparisons, largest adjusted p = 3.7e-11) and ahead of CAPGD in 14 of 15 retrained runs (one tie), with five seeds (`results/seeds_*.json`).
* FFE is **white-box** (reads the split thresholds). The surrogate attacks need far fewer target queries (they pre-train a surrogate whose cost is not counted) and PSO/MOEVA are black-box, so query counts are not like-for-like.
* **Tree-split boundary snapping adds at most three points of Real ASR** and costs up to 1.8x the queries (ablation `FFE without TSBS`); most of the success comes from Lie-cone steering.
* The operational cost of FFE's evasions is lowest by far under the paper's cost model, but FFE steers by that cost; in normalized L1 FFE is not smaller than PSO on two corpora.
* "Feasible" means conformant to the 12-feature schema (5% tolerance on the coupled rates, identical for all methods); no packets were replayed.
* All results are conditional on detection: cohorts are malicious test flows that both models detect when clean (77.6% / 99.8% / 87.0% of the test attacks).
* LightGBM on CIC-IDS2017 is evaded in only 35.1% of the cohort (XGBoost 99.2%); the reason is not analysed.
* CAPGD and the NIDSGAN-style generator are our re-implementations (one small MLP surrogate, default budgets). The white-box tree attacks (LT-Attack, Cascioli et al.) are cited but not run.

Defenses on CSE-CIC-IDS2018 (Real ASR on the detected cohort; clean accuracy 97.3% for all models): undefended 84.1 / 98.9 / 88.3 (FFE M=5, FFE M=20, CAPGD), MPS 78.8 / 78.8 / 71.9, LGAT 46.5 / 80.3 / 74.3, MPS+LGAT 62.0 / 62.0 / 55.1. LGAT mainly protects against the attack it was trained on; no configuration brings evasion below 46%. Earlier 12,000-flow runs that reported a "malleability penalty trap" and 5.3% for MPS+LGAT are not reproduced at full scale and were removed (`results/legacy_12k_benchmark_results.json` is kept for the record).

## 3. Repository structure

```
adversarial_ids/
├── paper/                       # Manuscript (elsarticle), supplementary, highlights, references.bib
│   ├── tables/                  # LaTeX tables generated by experiments/summarize_results.py
│   └── build.sh                 # pdflatex/bibtex build of manuscript, supplementary and highlights
├── src/
│   ├── datasets/
│   │   ├── full_data.py         # full-scale builders: raw files -> deduplicated parquet, stratified split
│   │   ├── schema.py            # 12-feature schema, invariants, projection P_M (scalar + vectorised)
│   │   ├── real_data_loader.py  # legacy 12,000-flow samplers (kept for the unit tests only)
│   │   └── generator.py         # legacy generator wrappers and synthetic fallbacks
│   ├── models/tree_models.py    # XGBoost (CUDA), LightGBM, CatBoost (with split extraction), Random Forest
│   └── attacks/
│       ├── flow_field_evasion.py  # FFE: Lie cone + TSBS (switchable)
│       ├── baselines.py           # ZOO, HopSkipJump, MOEVA, Traffic Manipulator PSO
│       ├── modern_baselines.py    # CAPGD (surrogate transfer) and NIDSGAN-style generator
│       ├── cost.py                # the paper's operational cost, applied identically to every attack
│       └── unconstrained.py       # naive feature-space attack
├── experiments/
│   ├── run_full_benchmark.py    # master benchmark -> results/full_<dataset>.json (per-flow outcomes)
│   ├── run_seeds.py             # five retrained seeds for FFE / CAPGD / NIDSGAN-style
│   ├── run_ablations.py         # step budget, generator subsets, cost regimes, snapping offset
│   ├── run_transferability.py   # cross-architecture transfer
│   ├── run_defenses.py          # MPS (masked columns), LGAT, MPS+LGAT vs FFE M=5/20 and CAPGD
│   ├── summarize_results.py     # JSON -> paper/tables/*.tex, results/summary.json (McNemar+Holm, root splits)
│   └── common.py                # full-data loading, cohort selection, ColumnMaskedModel
├── tests/                       # pytest suite
└── results/                     # per-flow outcomes and summaries
```

## 4. Reproduction

Environment used: Python 3.13.11, PyTorch 2.6.0+cu124, XGBoost 3.4.1, LightGBM 4.7.0, CatBoost 1.2.10, scikit-learn 1.8.0, NVIDIA RTX 5000 Ada (16 GB). See `requirements.txt`. Import `xgboost`/`lightgbm` before `torch` (the reverse order segfaults on this setup).

```bash
git clone https://github.com/vinhqdang/adversarial_ids.git && cd adversarial_ids
pip install -r requirements.txt

# 1. download the raw captures (about 4 GB; UNSW-NB15 from the Hugging Face mirror wwydmanski/UNSW-NB15)
python -c "from src.datasets.full_data import download_raw, build_full_dataset; \
[download_raw(d) for d in ('cse2018','cic2017','unsw')]; [build_full_dataset(d) for d in ('cse2018','cic2017','unsw')]"

# 2. experiments (the three benchmarks can run in parallel; about 1.5 h each on a 32-core workstation)
python experiments/run_full_benchmark.py --datasets unsw cic2017 cse2018 --n-fast 1000 --n-slow 200
python experiments/run_seeds.py --seeds 1 2 3 4 5 --n 300
python experiments/run_ablations.py && python experiments/run_transferability.py && python experiments/run_defenses.py

# 3. tables and statistics, then the paper
python experiments/summarize_results.py
bash paper/build.sh

pytest
```

## 5. Responsible disclosure

This work was conducted on public academic intrusion datasets. Its aim is to expose structural weaknesses in ML detectors and motivate invariant-aware robust training, not to facilitate attacks.
