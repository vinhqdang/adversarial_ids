# Steering Through the Trees: Physical Lie Vector Field Evasion of Tree Ensembles in Network Intrusion Detection

[![Python 3.13](https://img.shields.io/badge/python-3.13-blue.svg)](https://www.python.org/)
[![CUDA Accelerated](https://img.shields.io/badge/CUDA-XGBoost%20CUDA-green.svg)](https://developer.nvidia.com/cuda-toolkit)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)
[![Target Journal](https://img.shields.io/badge/Journal-Elsevier%20Information%20Sciences-orange.svg)](https://www.sciencedirect.com/journal/information-sciences)

Reference implementation of **Flow-Field Evasion (FFE)**, a constraint-preserving, query-efficient evasion attack against gradient-boosted tree ensembles in flow-based network intrusion detection. FFE models four protocol-compliant attacker actions as infinitesimal generators of a Lie cone on the physical flow manifold and finishes with tree-split boundary snapping (TSBS).

## 1. What the benchmark measures

All results are computed on the **complete, deduplicated** CSE-CIC-IDS2018, CIC-IDS2017 and UNSW-NB15 captures (no sampling), mapped to a 12-feature flow schema.

| Dataset | Valid records | Flows kept (dedup, no label conflicts) | Attacks | Train / Test |
| :--- | ---: | ---: | ---: | :--- |
| CSE-CIC-IDS2018 | 6,468,390 | 4,300,373 | 543,806 | 3,010,261 / 860,075 |
| CIC-IDS2017 | 2,097,825 | 1,692,949 | 405,355 | 1,185,065 / 338,590 |
| UNSW-NB15 | 215,742 | 120,317 | 53,502 | 84,221 / 24,064 |

Notes: the distributed CSE-CIC-IDS2018 files are capped at 1,048,575 rows each; the UNSW-NB15 files used are the official training/testing partition (257,673 records, 215,742 TCP/UDP), a subset of the 2.54 million records of the complete capture. Duplicates and label-conflicting records are removed *before* the stratified 70/10/20 split so no flow appears on both sides.

## 2. Main results (XGBoost target, Real ASR = evades **and** physically feasible)

Wilson 95% intervals are in `paper/tables/tab_master.tex`; every number below is regenerated by `experiments/summarize_results.py` from `results/full_*.json`.

| Method | CSE-CIC-IDS2018 | CIC-IDS2017 | UNSW-NB15 | Queries (range) |
| :--- | :---: | :---: | :---: | :---: |
| Unconstrained feature space | 38.1 | 17.8 | 9.2 | 36--75 |
| ZOO-NIDS | 14.9 | 9.0 | 0.0 | 76--137 |
| HopSkipJump-NIDS | 0.0 | 0.0 | 0.0 | 47 |
| CAA / MOEVA (N=200) | 21.0 | 31.5 | 14.5 | 250--434 |
| Traffic Manipulator PSO (N=200) | 60.0 | 32.0 | 43.5 | 161--262 |
| CAPGD, surrogate transfer | 99.5 | 55.2 | 26.8 | 1.1--15.0 |
| NIDSGAN-style generator | 70.5 | 55.5 | 13.6 | 2.2--4.5 |
| **FFE (ours)** | **100.0** | **95.9** | **61.5** | 13.0--91.4 |

* FFE is significantly better than PSO and CAA/MOEVA on every corpus (exact McNemar).
* On CSE-CIC-IDS2018 FFE and CAPGD are **statistically tied** (100.0 vs 99.5, McNemar p = 0.0625) and CAPGD needs fewer queries; FFE is significantly better on the other two corpora.
* LightGBM resists FFE on CIC-IDS2017 far better than XGBoost (34.6% vs 95.9%).
* The cost column of the paper favours FFE partly by construction (FFE steers by that cost); see the paper's Section 4.
* CAPGD and the NIDSGAN-style generator are our re-implementations against a small MLP surrogate, not the authors' code.

Defenses on CSE-CIC-IDS2018 (FFE at M=5, 300 detected flows): undefended 96.3% ASR, malleability masking (MPS) 67.0%, Lie-guided adversarial training (LGAT, 5,000 augmented flows) 33.0%, MPS+LGAT 38.0% (not distinguishable from LGAT at this cohort size). Clean accuracy is 98.04% for every model. Earlier, smaller-sample runs that reported a "malleability penalty trap" and 5.3% for MPS+LGAT are **not reproduced** at full scale; the old results are kept in `results/legacy_12k_benchmark_results.json` for the record only.

## 4. Reproduction

Environment used: Python 3.13.11, PyTorch 2.6.0+cu124, XGBoost 3.4.1, LightGBM 4.7.0, CatBoost 1.2.10, scikit-learn 1.8.0, NVIDIA RTX 5000 Ada (16 GB). See `requirements.txt`.

```bash
git clone https://github.com/vinhqdang/adversarial_ids.git && cd adversarial_ids
pip install -r requirements.txt

# 1. download the raw captures (about 4 GB; UNSW-NB15 comes from the Hugging Face mirror wwydmanski/UNSW-NB15) and build the deduplicated datasets
python -c "from src.datasets.full_data import download_raw, build_full_dataset; \
[download_raw(d) for d in ('cse2018','cic2017','unsw')]; [build_full_dataset(d) for d in ('cse2018','cic2017','unsw')]"

# 2. experiments (about 3 h for the full benchmark on one GPU workstation)
python experiments/run_full_benchmark.py --datasets unsw cic2017 cse2018 --n-fast 1000 --n-slow 200
python experiments/run_ablations.py && python experiments/run_transferability.py && python experiments/run_defenses.py

# 3. tables and statistics, then the paper
python experiments/summarize_results.py
bash paper/build.sh

# tests
pytest
```

## 5. Responsible disclosure

This work was conducted on public academic intrusion datasets. Its aim is to expose structural weaknesses in ML detectors and motivate invariant-aware robust training, not to facilitate attacks.
