\paragraph{Metric Definitions}
In Table~\ref{tab:master_evasion_benchmark}, we report six performance dimensions:
\begin{enumerate}
    \item \textbf{Attack Success Rate (ASR):} The percentage of attacks where the model output probability drops below the detection threshold ($P(\text{Malicious} \mid x^*) < 0.5$).
    \item \textbf{Physical Feasibility Rate (PFR):} The percentage of generated adversarial samples that pass all protocol sanity checks, non-negative packet counts, and exact coupled rate equations ($x^* \in \mathcal{M}_{\text{flow}}$).
    \item \textbf{Real Attack Success Rate (Real ASR):} The percentage of attacks that simultaneously achieve both classifier evasion \emph{and} physical feasibility:
    \begin{equation}
        \text{Real ASR} = \frac{1}{N} \sum_{i=1}^N \mathbb{I}\left[ F(x_i^*) < 0 \;\land\; x_i^* \in \mathcal{M}_{\text{flow}} \right]
    \end{equation}
    \item \textbf{Average Queries:} Mean number of model evaluations required per sample.
    \item \textbf{Average Perturbation Cost ($L_1$):} Weighted operational cost metric $\sum_{i} w_i |x_i^* - x_i|$.
    \item \textbf{Total Execution Time:} Wall-clock time required to evaluate all 100 attack flows on the GPU workstation.
\end{enumerate}

\subsubsection{Detailed Empirical Findings}

\paragraph{1. The Complete Collapse of Real ASR in Existing Methods}
While unconstrained algorithms claim high mathematical evasion in theoretical papers, their \textbf{Real ASR} collapses in practice. The naive coordinate descent method achieves 0.0\% Real ASR because it gets trapped in local minima. ZOO-NIDS and HopSkipJump achieve Real ASRs of only 2.0\% and 8.0\%, respectively; their unconstrained continuous mutations produce decoupled byte/packet rates that fail physical invariant checks.

\paragraph{2. Perfect Evasion with Guaranteed Feasibility (100\% Real ASR)}
Flow-Field Evasion achieves a \textbf{100.0\% Attack Success Rate} and a \textbf{100.0\% Physical Feasibility Rate}, resulting in an unprecedented \textbf{100.0\% Real ASR}. Because every infinitesimal step in FFE is constrained to the positive Lie Cone $\mathcal{K}_{\text{net}}(x)$, it is mathematically impossible for FFE to produce a flow that violates physical conservation laws.

\paragraph{3. Two-Orders-of-Magnitude Query Reduction}
FFE requires an average of only \textbf{9.1 model queries} per sample. In stark contrast:
\begin{itemize}
    \item HopSkipJump requires 680 queries (74$\times$ more queries than FFE).
    \item CAA / MOEVA requires 1,240 queries (136$\times$ more queries than FFE).
    \item Traffic Manipulator PSO requires 1,850 queries (203$\times$ more queries than FFE).
\end{itemize}
This dramatic reduction occurs because FFE evaluates directional Lie derivatives along the four physically admissible generators rather than searching blindly across the 12-dimensional continuous space.

\paragraph{4. Sub-Second Execution Latency}
FFE executes 100 full attack flows in \textbf{2.80 seconds}, equating to an average latency of \textbf{28 milliseconds per flow}. Conversely, Traffic Manipulator takes 420.15 seconds (over 7 minutes). This 150$\times$ speedup makes real-time inline packet manipulation computationally viable on production network interface cards.

\subsubsection{Behavioral Analysis by Attack Family}
\begin{itemize}
    \item \textbf{Volumetric DoS \& UDP Floods (Families 1 \& 2):} The primary signature exploited by tree splits is extreme flow byte rate ($x_8$) and packet rate ($x_9$). FFE identifies the Temporal Dilation generator $\vec{v}_{\text{time}}$ as having the highest negative Lie derivative per unit cost. Extending flow duration smoothly dilutes byte and packet rates, crossing decision thresholds in only 7--8 queries.
    \item \textbf{Brute Force Authentication (Family 3):} Repetitive credential submissions exhibit fixed forward packet lengths ($x_{10}$). FFE primarily engages the Payload Padding generator $\vec{v}_{\text{pad}}$, injecting dummy application bytes that shift the mean packet length across the model's split boundary.
    \item \textbf{Web Application Exploits (Family 4):} SQLi and XSS flows exhibit high request-to-response packet asymmetry. FFE injects dummy forward keep-alives via $\vec{v}_{\text{chaff}}$, balancing packet ratios and matching benign HTTP browsing distributions.
    \item \textbf{Infiltration (Family 5):} Covert beacons already have low volumetric footprints but are flagged by distinct botnet window sizes ($x_7$). FFE immediately selects the Window Morphing generator $\vec{v}_{\text{win}}$, flipping the window to standard client OS values ($64,240$) and achieving evasion in only 6.4 queries.
\end{itemize}
